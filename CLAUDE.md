# VRtrip — инструкция для Claude и других ИИ

Просмотр архитектурных 3D-моделей в браузере, шлеме (Meta Quest 3/3S) и AR на телефоне.
Сайт: https://vashevich.github.io/vrtrip/ (GitHub Pages из ветки `main`, сборки нет).
Проект офиса OFFX: правила работы, журнал и роли — в репозитории `Vashevich/OFFX`, файл `ПРИВЕТ.md`.

## Файлы
| Файл | Что в нём |
|---|---|
| `index.html` | почти вся программа: стили (≈ строки 15–567), разметка панели (≈ 570–1015), один модуль JavaScript (≈ 1016–7100) |
| `furniture.js` | каталог болванок мебели: 65 предметов, 11 разделов, построение геометрии. **Общий с Табуреткой** (`Vashevich/taburetka`, `js/furniture.js`) |
| `gumball.js` | гамбол (стрелки, квадратики, точка-центр, дуги, кубики, ручки частей). Ничего не знает о приложении: рисует ручки, находит ручку под лучом, считает протяжку |
| `tests/` | автотест `smoke.py` и тестовые модели (`make_models.py`, описание — `tests/README.md`) |
| `.github/workflows/smoke.yml` | автотест на GitHub при каждой выкладке в `main` |

Библиотеки с CDN (importmap в `index.html`): three.js 0.160, three-mesh-bvh 0.7.3; JSZip 3.10 — обычным `<script>`.

## Правила работы
- **Перед правкой** найди раздел по заголовку и прочитай его целиком; соседние разделы связаны через общие переменные модуля.
- **Общие файлы с Табуреткой** (`furniture.js`; дальше — `gumball.js`): правка делается сразу в обоих репозиториях одним и тем же текстом.
- **Проверка:** `python3 -m http.server 8766 &` и `python3 tests/smoke.py` (подробно — `tests/README.md`). Без видеокарты Chromium рисует медленно: прогон идёт минуты, время загрузки не показательно.
- **Выкладка:** высокий риск (правило 11 офиса) — в `main` по слову Сергея или после проверки ★ Толи; иначе ветка. Откат — `git revert`.
- **Хранение у пользователя** (`localStorage`, IndexedDB) меняется только с обратной совместимостью: старые сохранения должны открываться.
- Тексты интерфейса — по-русски, коротко; комментарии в коде — по-русски или по-английски, как в соседних строках.

## План разделения на модули (решение Сергея и ★ Фрола, 17.11.2026)
Выносим по ходу задач: тронули раздел — перенесли его в свой файл, как `gumball.js`. Целевая раскладка:
```
index.html            разметка панели
css/vrtrip.css        стили
js/main.js            запуск и главный цикл
js/core/              сцена, состояние, хранение, помощники
js/models/            форматы, конвейер геометрии, сборка моделей, экспозиция
js/render/            свет, тени, подача, обводка и сглаживание
js/tools/             разметка, рулетка, карандаш, сечение, выделение, реперы
js/walk/              физика, прогулка, VR-очки, взрыв-схема, гаджеты
js/xr/                шлем: панели, контроллеры, ввод
js/ar/                AR на телефоне
furniture.js, gumball.js — общие с Табуреткой
```
Модуль получает зависимости через импорт или явный объект (сцена, камера, состояние); глобальные переменные между файлами не заводим.
