# VRtrip

Просмотр архитектурных OBJ-моделей в Meta Quest 3 и в обычном браузере.

**Открыть:** https://vashevich.github.io/vrtrip/

Автор — Сергей Дмитриев, Rock Parametric.

## Режимы
- **Прогулка в браузере** — от первого лица на компьютере, телефоне или в окне браузера Quest (WASD / джойстик, мышь, этажи).
- **VR · сквозной режим** — модель в реальной комнате (Quest 3, passthrough).
- **VR · с окружением** — полное погружение: небо, земля, горизонт.

## Возможности
- Загрузка OBJ + MTL + текстуры или ZIP; несколько моделей в экспозиции.
- Ходьба с гравитацией (полы, лестницы), стены, переход между этажами, телепорт.
- Масштаб двумя грипами (как в Gravity Sketch / Open Brush); кнопка A — 1:1 ↔ макет, макет запоминает положение.
- Разметка: куб, метка с комментарием, рулетка с привязкой к вершинам, карандаш, ластик, отмена; экспорт и импорт заметок в JSON; снимок экрана.

Модели и заметки хранятся только в браузере устройства.
