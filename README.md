# VRtrip

Просмотр архитектурных OBJ-моделей в Meta Quest 3 прямо в браузере шлема: прогулка 1:1, макет на столе, сквозной режим (passthrough), экспозиция из нескольких моделей.

**Открыть:** https://vashevich.github.io/vrtrip/

Загрузка: OBJ + MTL + текстуры или один ZIP. Модели хранятся только в браузере устройства.
