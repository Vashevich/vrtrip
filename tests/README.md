# Тесты VRtrip

**Тёма (3D-технолог)** — `make_models.py` генерирует набор тестовых моделей в `tests/models/`:

| Файл | Что проверяет |
|---|---|
| 01_pavilion_m.obj + .mtl | обычная модель в метрах, материалы |
| 02_rhino_zup_mm.obj | как из Rhino: ось Z вверх, миллиметры — авто-единицы и авто-ось |
| 03_pavilion_zip.zip | ZIP с OBJ и MTL внутри папки |
| 04_missing_mtl.obj | OBJ ссылается на MTL, которого нет — должно быть предупреждение |
| 05_pavilion.glb | glTF/GLB с цветами |
| 06_tower_mm_zup.stl | STL, 5 этажей, мм, Z вверх |
| 07_pavilion.ply | PLY |
| 08_broken.obj | битый файл — грузится с предупреждением, без падения |
| 09_empty.obj | пустой файл — понятная ошибка |
| 10_tiny_part_mm.obj | деталь 40 мм — авто-единицы на маленьком объекте |
| 11_masterplan_km.obj | площадка 1,2 км — тени, отсечение, масштаб AR |
| heavy_300k / heavy_1m | тяжёлые (300 тыс. и 1 млн треугольников), не хранятся в git — `python3 tests/make_models.py` |

Нет генератора для FBX, 3DM, 3DS, DAE, USDZ — нужны реальные файлы из практики.

**Тимур (QA)** — `smoke.py` прогоняет страницу в браузере без шлема: три раскладки (компьютер, телефон вертикально и горизонтально), все тестовые модели, режимы, инструменты, ошибки JavaScript. Скриншоты и отчёт — в `tests/shots/`.

```
python3 -m http.server 8766 &
python3 tests/smoke.py            # --heavy — с тяжёлыми моделями, --only=desktop — одна раскладка
```

Тот же прогон запускается на GitHub при каждой публикации (вкладка Actions).
Время загрузки в этом прогоне не показательно: браузер рисует без видеокарты. Скорость меряем на Quest 3S.

Что автотест **не** проверяет (только руками, на занятии): шлем (VR, сквозной режим, контроллеры, руки), AR на телефоне, гироскоп в режиме VR-очков, Quick Look на iPhone, реперы.
